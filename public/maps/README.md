office-data.json, 6 Ekim 2026 tarihinde Overpass API üzerinden alınan küçük bir bölgenin özgün açık harita verisidir. Astor Business Center, OSM 1378843903 numaralı yapı ile belirlenmiştir. Verinin kaynak bildirimi JSON içindeki osm3s.copyright alanında korunmuştur.

office-map.svg, bu veriden scripts/build-office-map.mjs ile üretilir. Görüntü site tarafından sunulur. Ziyaretçi tarayıcısı harita için üçüncü taraf tile, iframe veya takip hizmetine bağlanmaz.
